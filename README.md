# SecureGuard AI — E-Commerce Security Monitoring System

A production-ready SaaS platform for e-commerce cybersecurity monitoring with React, TypeScript, Tailwind CSS, Vite, Express, and PostgreSQL.

## Folder structure

- `frontend/` — React app with dashboard pages, landing page, auth, charts, and responsive UI.
- `backend/` — Express API with authentication, dashboard data, orders, alerts, customers, reports, integrations, and billing endpoints.
- `db/` — PostgreSQL schema and seed scripts.

## Quick start

### Frontend

```bash
cd secureguard-ai/frontend
npm install
npm run dev
```

### Backend

```bash
cd secureguard-ai/backend
npm install
npm run dev
```

### Database

Create a PostgreSQL database and import `db/schema.sql`.
